# APIDACS Global Finding Lifecycle Procedure

This archive contains the system-wide APIDACS finding lifecycle specification.

- `APIDACSI.md`: Complete procedure from discovery through investigation, classification, impact assessment, approval, remediation, verification, closure, and continuous monitoring.

The document is deliberately project-agnostic. It contains no project-specific scan totals, repository paths, package names, programming-language assumptions, or initial-backlog counts.
